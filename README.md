I am a **Platform Engineering & Site Reliability Engineering (SRE)** focused developer with a background in Machine Learning and Systems Programming. My focus lies in building **scalable cloud infrastructure, automated CI/CD pipelines, and ML-driven observability systems (AIOps)** that increase system uptime and developer velocity.

- 🔭 **Core Focus:** Platform Automation, Kubernetes Orchestration, Observability, and DevSecOps.
- 🛠️ **Engineering Mindset:** Eliminating toil, implementing GitOps workflows, and defining SLO/SLI metrics.
- ⚡ **Currently:** Deep-diving into **Go (Golang)** internal mechanics, **Kubernetes Operators**, and preparing for the **CKA (Certified Kubernetes Administrator)**.
- 🎓 **Education:** Master of Computer Applications (MCA) @ VESIT, Mumbai (*Graduating 2027*).
