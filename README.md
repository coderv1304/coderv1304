#### 🐧 [linux-administration](https://github.com/coderv1304/linux-administration)
5 Bash scripts + a systemd-managed service for common Linux admin tasks — backup with retention pruning, CPU/memory/disk threshold monitoring, dependency checks, user management, and log rotation. The monitor script runs every 5 minutes via a `systemd` timer, and every script passes `shellcheck` with zero warnings.

#### 🛡️ [network-anomaly-detection](https://github.com/coderv1304/network-anomaly-detection)
A full-stack ML application that classifies network flows as benign or malicious in real time. Random Forest classifier trained on the CIC-IDS-2017 benchmark, served through a Flask + Socket.IO app with a live monitoring dashboard, batch CSV analysis, and a Wi-Fi traffic simulator. Container-ready with a GitHub Actions CI pipeline (lint, Bandit SAST, dependency scanning) and a roadmap toward drift detection, MLflow, and Prometheus/Grafana monitoring.
